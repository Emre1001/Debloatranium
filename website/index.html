Get the ads, telemetry and Copilot out of Windows.

Debloatranium is a free, open-source tool for Windows 10 and 11. You choose how far it should go and which programs to install, and it takes care of the rest. It sets a restore point before it changes anything.

How it works

The app is a short wizard. These are the actual screens.

  1. Pick a language

    English, German or Turkish. You can change it later.

  2. Check your hardware

    Turn off Wi-Fi, Bluetooth or printer services if your PC doesn't use them. Everything stays on unless you switch it off.

  3. Preset or custom

    Presets are the quick way. Custom lists every single setting so you can decide one by one.

  4. Choose a level

    Four levels, from Minimal to Zero. Each one adds to the previous. Zero also uninstalls preinstalled apps like Clipchamp, Solitaire and the Xbox app.

  5. Apps and extras

    Pick programs to install through winget, Microsoft's package manager. This is also where you find the GPU driver, the power plan, cleanup options and the optional Edge removal.

  6. Review and run

    You get a summary first. Then a progress screen shows each step as it runs, and at the end you can restart your PC from the app.

Questions

Can I undo the changes?

Yes, for all settings: switching one off puts the Windows default back. Removed apps are the exception. A System Restore Point is created before the first change, so you can roll back the whole system as well.

Do I need admin rights?

For most changes, yes. If you start the app without them, it shows a button to restart it as administrator.

Does it need to be installed?

No. It's a single .exe of about 8 MB. It uses WebView2, which is part of Windows 10 (version 1803 and later) and Windows 11.

What about Microsoft Edge?

Edge removal is optional and marked as risky in the app. It works, but Windows Update may install Edge again.

Does Debloatranium collect any data?

No. There's no account, no analytics and no ads. The full source code is on GitHub.

Which Windows versions are supported?

Windows 10 from version 1803 and Windows 11. A few settings, such as the left-aligned taskbar, only have an effect on Windows 11.
