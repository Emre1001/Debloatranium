    06 FAQ

    Fair questions.

    Is it safe?

    Registry tweaks are reversible — switching one off restores the Windows default. A System Restore Point is created before anything runs. Review what you enable; you are in control of every change.

    What can't be undone?

    Removing built-in apps (level Zero) and uninstalling Edge are one-way. Edge removal is experimental — Windows Update may bring it back.

    Do I need administrator rights?

    For telemetry, services and drivers, yes. If you start it normally, Debloatranium offers a one-click relaunch as Administrator.

    Does it need to be installed?

    No. It's a single portable .exe of about 8 MB. It uses WebView2, which is already part of Windows 10 (1803+) and Windows 11.

    Which Windows versions?

    Windows 10 (1803 and newer) and Windows 11. A few tweaks, like the left-aligned taskbar, only apply on Windows 11.

    Is it really free?

    Yes. MIT licensed, no account, no ads, no telemetry of its own. If it made your PC faster, a donation is welcome.
